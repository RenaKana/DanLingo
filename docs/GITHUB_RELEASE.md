## 生成候选

```sh
pnpm run check:source
pnpm run prepare:github
```

生成新的 `.artifacts/github-prep/source-*/repository` 和同级 `manifest.json`。清单记录每个文件的大小和 SHA-256；候选包括源码、离线测试、开发工具、选定维护文档、CI 与已固定来源的运行时。不包含本地凭据、生成目录、旧 ZIP、浏览器资料、模型权重和历史验收报告。

生成器不会初始化 Git、创建提交、配置远端、推送或发布。有 Git 仓库时，它同时检查实际暂存文件和暂存字节，禁止忽略文件被强行暂存后绕过检查。源文件修改后应重新生成候选。在候选目录按 [开发步骤](DEVELOPMENT.md) 安装与验证，确认它不依赖私人工作目录的生成物。

## 已知限制与安全边界

- 平台主世界通过网页消息桥交付事件，同一网页脚本可伪造形状正确的事件；来源标签和消息 nonce 不构成同源脚本之间的安全隔离。用户启用并授权服务后，页面控制的数据可能触发翻译和相应消耗。每日请求上限是次数限制，费用额度仍应在服务方设置。
- 本地模型内容身份、加载前核验和取消行为是首发必验项；大文件的核验时间取决于磁盘和文件大小。不得仅凭路径、大小、修改时间判定内容未变。
- 可选浏览器工具使用明确配置或已安装环境，不自动下载浏览器。隔离 Chromium、模拟服务和合成消息检查不能作为 Chrome／Edge、真实 Provider 或真实平台验收。

源码检查仅扫描候选字节中的常见令牌特征和可识别的本地测试 Key，不扫描 Git 历史，不证明所有敏感信息或版权问题都已排除。
