# 隐私与权限

远程翻译把待译文字或受保护占位符、源／目标语言、模型和翻译 ID 发给用户配置的服务，不主动附送网站 Cookie、账号信息、作者、视频画面或整页内容。文字本身也可能含个人信息，服务方的数据规则需用户自行了解。

配置的服务 Key 随在线请求的 `Authorization` 头发送到用户授权并配置的服务 origin。网页不能读取该 Key 或选择其他目标，但同一网页脚本可以提供或伪造消息桥上的文本；翻译启用时，这些内容可能产生服务用量。每标签页滚动限额（每 60 秒 1,200 个唯一条目／60,000 原文字符）和并发限制之外，还有跨标签页、跨在线服务共享的每日请求上限，默认 3,000 次，按本机自然日持久保存，后台重启不会清零。计数无法可靠保存或已达上限时停止在线发送。请求次数不是金额上限，建议另为服务 Key 设置服务方费用额度。

本地后端在扩展内读取用户选择的模型并推理。模型不随源码提供，目录扫描针对用户授权目录。开发诊断、真实平台探针与性能测试是额外工具，不属于默认离线 CI。

## 凭据与存储

API Key 由扩展后台管理，不进入网页主世界或翻译消息。扩展设置页用于输入和管理凭据。“记住 Key”使用浏览器本机扩展存储，不是操作系统保险库或加密保险箱；会话 Key 随浏览器会话管理。

Key 绑定精确 origin（协议、域名、端口）。浏览器主机权限不能隔离端口，后台还需校验实际配置。修改服务 origin 不自动沿用旧 Key。

译文存于扩展 IndexedDB，缓存身份包含原文、资源、语言、后端／模型与翻译策略，有时间、条数和大小限制。模型文件、目录授权和元数据也存于扩展浏览器存储。每日请求计数单独保存在 IndexedDB，保留各日用量以防调整系统日期后重置计数，不含原文、译文或 Key。删除 Key、清缓存和移除模型分别执行，均不会重置在线请求计数。

## 权限

| 权限 | 用途 |
| --- | --- |
| `storage` | 设置与用户选择记住的凭据 |
| `offscreen` | 本地模型离屏扩展页 |
| Niconico / YouTube / Bilibili 指定主机 | 内容脚本及原生页面适配 |
| 可选 HTTP / HTTPS 主机 | 用户操作时授权配置的翻译服务 |
| 扩展内 WASM | 打包的本地推理运行时 |

可选通配范围不等于全部网站已授权。公网要求 HTTPS；HTTP 需显式启用并限制为本机／私有 IPv4。可访问设置页服务于站内设置入口，不能因此允许网站执行任意后台操作。

## 源码分享

`pnpm run prepare:github` 生成白名单源码候选，扫描常见令牌特征和已知本地测试凭据，排除本地生成物、真实服务配置与浏览器资料。扫描不能证明所有变形、未知或图像内敏感信息都不存在；共享前仍需核对文件清单。
